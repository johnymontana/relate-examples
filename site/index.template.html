Relate browser examples

Relate is an embedded openCypher graph database. On these pages it runs as WebAssembly inside your browser tab: no server holds your data, and nothing you type is sent anywhere except the downloads each example lists.

    {{EXAMPLES}}

What your browser needs

  • WebAssembly, ES module workers and the Origin Private File System, with synchronous access handles in workers. Current Chrome and Edge are tested; Firefox should work; Safari is untested.
  • Storage. Each example keeps its databases and any downloaded model files in this site's storage, under names prefixed with the example's number, so examples never share or overwrite each other's data. Clear them from the example's own page or from your browser's site settings.
  • A desktop-sized window. The pages are not designed for phones.

Every page states what it is about to download, and how large it is, before it downloads it. Pages that cannot run in your browser say why instead of failing midway.
