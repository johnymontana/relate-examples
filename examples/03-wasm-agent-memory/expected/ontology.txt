What the specification's SDK says of the document, the document against the schema the engine holds
(web/memory.js SCHEMA), the rules the engine does not enforce against every store the conversations
build, what its questions return, and what the Ontology tab searches and draws.

## The rules the engine does not enforce (web/ontology.js rules)
17 rules, 18 statements. Each statement returns the rule's violations, or the rows the rule is judged on:
values     Message.role: Message.role is one of: user
             MATCH (n:Message) WHERE n.role IS NOT NULL RETURN n.id AS id, n.role AS value ORDER BY id
values     Entity.key: Entity.key matches ^[a-z0-9]+( [a-z0-9]+)*$
             MATCH (n:Entity) WHERE n.key IS NOT NULL RETURN n.key AS id, n.key AS value ORDER BY id
values     Memory.kind: Memory.kind is one of: fact, decision, preference, note
             MATCH (n:Memory) WHERE n.kind IS NOT NULL RETURN n.id AS id, n.kind AS value ORDER BY id
values     Memory.slot: Memory.slot matches ^([^/]+/[^/]+)?$
             MATCH (n:Memory) WHERE n.slot IS NOT NULL RETURN n.id AS id, n.slot AS value ORDER BY id
counts     IN_SESSION from: every Message has exactly 1 IN_SESSION going out
             MATCH (x:Message) OPTIONAL MATCH (x)-[r:IN_SESSION]->() WITH x, count(r) AS n WHERE n <> 1 RETURN x.id AS id, n ORDER BY id
counts     IN_SESSION to: every Session has at least 1 IN_SESSION coming in
             MATCH (x:Session) OPTIONAL MATCH (x)<-[r:IN_SESSION]-() WITH x, count(r) AS n WHERE n < 1 RETURN x.id AS id, n ORDER BY id
counts     MENTIONS to: every Entity has at least 1 MENTIONS coming in
             MATCH (x:Entity) OPTIONAL MATCH (x)<-[r:MENTIONS]-() WITH x, count(r) AS n WHERE n < 1 RETURN x.key AS id, n ORDER BY id
counts     FROM from: every Memory has exactly 1 FROM going out
             MATCH (x:Memory) OPTIONAL MATCH (x)-[r:FROM]->() WITH x, count(r) AS n WHERE n <> 1 RETURN x.id AS id, n ORDER BY id
counts     FROM to: every Message has at least 1 FROM coming in
             MATCH (x:Message) OPTIONAL MATCH (x)<-[r:FROM]-() WITH x, count(r) AS n WHERE n < 1 RETURN x.id AS id, n ORDER BY id
counts     SUPERSEDES from: every Memory has at most 1 SUPERSEDES going out
             MATCH (x:Memory) OPTIONAL MATCH (x)-[r:SUPERSEDES]->() WITH x, count(r) AS n WHERE n > 1 RETURN x.id AS id, n ORDER BY id
counts     SUPERSEDES to: every Memory has at most 1 SUPERSEDES coming in
             MATCH (x:Memory) OPTIONAL MATCH (x)<-[r:SUPERSEDES]-() WITH x, count(r) AS n WHERE n > 1 RETURN x.id AS id, n ORDER BY id
invariants one-current-memory-per-slot: At most one memory in a slot is current.
             MATCH (m:Memory) WHERE m.current AND m.slot <> '' WITH m.slot AS slot, count(m) AS current WHERE current > 1 RETURN slot, current
invariants replaced-means-not-current: A memory is current exactly when nothing supersedes it, and it has a supersededAt exactly when it is not current.
             MATCH (m:Memory) WITH m, EXISTS { (m)<-[:SUPERSEDES]-(:Memory) } AS replaced WHERE m.current = replaced OR m.current = (m.supersededAt IS NOT NULL) RETURN m.id AS id
invariants supersession-stays-in-its-slot: A memory supersedes an older memory in its own slot, which is not the empty one, and stamps it with its own time.
             MATCH (newer:Memory)-[:SUPERSEDES]->(older:Memory) WHERE newer.slot = '' OR newer.slot <> older.slot OR newer.seq <= older.seq OR older.supersededAt <> newer.at RETURN newer.id AS newer, older.id AS older
invariants memory-carries-its-message-time: A memory's seq and at are those of the message it came from.
             MATCH (m:Memory)-[:FROM]->(msg:Message) WHERE m.seq <> msg.seq OR m.at <> msg.at RETURN m.id AS id
invariants about-only-what-its-message-mentions: A memory is ABOUT only entities that its own message MENTIONS.
             MATCH (m:Memory)-[:ABOUT]->(e:Entity) WHERE NOT EXISTS { (m)-[:FROM]->(:Message)-[:MENTIONS]->(e) } RETURN m.id AS id, e.key AS entity
declared   declared: every node, relationship and property in the store is one the document declares
             MATCH (n) RETURN labels(n) AS labels, keys(n) AS keys, count(*) AS nodes
             MATCH (a)-[r]->(b) RETURN type(r) AS type, labels(a) AS source, labels(b) AS target, keys(r) AS keys, count(*) AS relationships
