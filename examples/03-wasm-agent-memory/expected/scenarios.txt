# Example 03: the scripted conversations on Relate 1.3.0 WASM (harness/run.mjs), as the page runs them

Each turn: what the user said, what each memory tool returned, and the reply. In a recall row,
[n] marks a memory the reply cites, then its score, how it was reached (search: a search hit;
update: the current version of a hit that had been replaced; graph: linked through shared entities),
how a hit was found (by meaning: the vector search, with the cosine similarity; by words: the
full-text search) and the path that reached it. Vectors: Xenova/all-MiniLM-L6-v2 (data/embeddings.json).
