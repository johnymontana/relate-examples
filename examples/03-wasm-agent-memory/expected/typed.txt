# Example 03: turns nobody scripted (web/agent.js freeTurn), after the "A teammate that remembers" conversation

No language model: a question goes to recall (or to connect, when it asks how two known entities are
linked, or on to trace, when it asks for a source); anything else is stored word for word as a note,
linked to the entities it names. The reply is assembled from what the tool returned. In the page a typed
text gets its vector from the model in the tab; here each has one in data/embeddings.json, but the last
two, which have none on purpose: the note is stored and found by its words alone, as it is in a tab
that could not load the model.
